# Test fixtures

Small media files used by decode/edit tests. **Every file must have a clear, GPL-compatible license**
(own photos, CC0, or generated by a script). Record the source and license of each file in
[`SOURCES.md`](SOURCES.md) when it is added.

## `images/` — generated, CC0

Everything in `images/` is **synthetic** and generated by [`generator/`](generator/), a small
developer tool that is *not* part of the main workspace (it needs libheif's x265 encoder and FFmpeg,
which CI doesn't have). The generated files are committed, so tests never need the tool.

The pictures are a gradient with a **red square top-left, green top-right and blue bottom-left**, so
tests check orientation and colours automatically. Files named `bad-*` are deliberately broken
(empty, random bytes, truncated, decompression-bomb headers): they must produce an error card, never
a crash or a hang.

Regenerate (Windows, from the repository root, after the media setup in `docs/setup-windows.md`):

```powershell
$env:VCPKG_ROOT = "$env:USERPROFILE\dev\kinora-tools\vcpkg"
$env:PATH = "$env:VCPKG_ROOT\installed\x64-windows\bin;$env:PATH"
$env:KINORA_FFMPEG = "$env:USERPROFILE\dev\kinora-tools\ffmpeg-n9.0-latest-win64-gpl-9.0\bin\ffmpeg.exe"
cargo run --manifest-path test_data/generator/Cargo.toml --target-dir target/generator
```

For a large folder to flick through by hand (500 mixed photos, not committed) use
`cargo xtask gen-folder <dir>`.
